# カードデータセットの形式
JSON Object形式に準ずる。

## プロパティの説明方法
この文書では、オブジェクトのプロパティは以下の形式で説明する。
```
 "(プロパティ名)" : (型),
```
ここで、`(型)`は以下のように説明される。
- 単一型 
  - `null`: 値無し
    - このプロパティ自体を省略可能。
  - `boolean`: `true`または`false`
  - `number`: 整数値
	- JSONの仕様上、小数表記も可能だが、小数点以下は無視される。
  - `string`: 文字列
	- `""`で囲まなければならない。
	- 途中で改行する場合は`\n`を使う。
  - 上記以外の場合、この文書で定義される独自の型を指している。
- 組み合わせ型
  - `A | B`: `A`または`B`
    - `null`を含む場合はプロパティ自体を省略可能。
  - `A[]`: `A`を要素とする配列

## 独自型

### DataSet
データセット全体を表すオブジェクト。
```
object DataSet
{
  "cards"  : Card[],
  "packs"  : CardPack[],
  "updated": string,
}
```
- `cards`: カード情報の配列
- `packs`: カードパック情報の配列
- `updated`: このデータセットの最終更新日時
  - 形式は`yyyy-MM-dd HH:mm:ss`
  - 日時として解釈できるなら他の形式でもよい。

### Card
カードの情報を表すオブジェクト。
```
object Card
{
  "id"       : number,
  "name"     : string,
  "ruby"     : string | null,
  "en_name"  : string | null,
  "type"     : string,
  "text"     : string,
  "unusable" : boolean | null,
  "monster_info" : MonsterInfo | null,
  "pendulum_info": PendulumInfo | null,
}
```
- `id`: カードID
  - 公式データベースにおいて、カード個別ページURLの`cid=***`の部分で確認できる。
- `name`: カード名
  - OCG発売済みのカードは日本語でのカード名。
  - TCG先行カードの場合は英語でのカード名。
- `ruby`: カード名の読み
  - OCG発売済みのカードは公式データベースの個別ページで確認できる。
  - OCG未発売のカードでは`null`(プロパティを省略)。
- `en_name`: 英語版のカード名
  - OCG発売済みのカードは公式データベースの個別ページで確認できる。
  - 英語版が未発売のカードでは`null`(プロパティを省略)。
  - TCG先行カードの場合は`name`の値と同じにする。
- `type`: カードタイプを表す文字列
  - 有効な値は後述の`enum CardType`を参照。
- `text`: カードテキスト
  - ペンデュラム効果は除く。
- `unusable`: 使用不可フラグ
  - 公式データベースにおいて「公式のデュエルでは使用できません」と書かれていれば`true`。
  - それ以外の場合は`false`や`null`(プロパティを省略)。
- `monster_info`: モンスター情報
  - ペンデュラム情報は除く。
  - モンスターでない場合は`null`(プロパティを省略)。
- `pendulum_info`: ペンデュラム情報
  - Pスケール及びP効果。
  - ペンデュラムモンスターでない場合は`null`(プロパティを省略)。

### モンスター情報
モンスターカードだけが持つ情報をまとめたオブジェクト。
```
object MonsterInfo
{
  "attribute": string,
  "type"     : string,
  "effect"   : boolean | null,
  "ability"  : string | null,
  "level"    : number,
  "atk"      : number,
  "def"      : number,
}
```
- `attribute`: 属性を表す文字列
  - 有効な値は後述の`enum Attribute`を参照。
- `type`: 種族を表す文字列
  - 有効な値は後述の`enum MonsterType`を参照。
- `effect`: 効果モンスターフラグ
  - 効果モンスターなら`true`。
  - 効果を持たないモンスターの場合は`false`や`null`(プロパティを省略)。
  - 注: これが`false`であっても「通常モンスター」とは限らない。カードタイプも確認する必要がある。
- `ability`: 能力を表す文字列
  - 有効な値は後述の`enum Ability`を参照。
  - 能力を持たない場合は`null`(プロパティを省略)。
  - 複数の能力を持つ場合(例: チューナーかつリバース)、それらを`/`で区切って全て書く(例: `チューナー/リバース`)。
- `level`: レベル/ランク/リンク
  - 「ルール上◯◯として扱う」とカードに書かれていても、★の数が0なら`0`とする(公式データベースに準拠)。
- `atk`: 攻撃力
  - 「?」の場合は`-1`にする。
- `def`: 守備力
  - 「?」の場合は`-1`にする。
  - リンクモンスターにおいてはリンクマーカーの向きを表す数値(後述)にする。

### ペンデュラム情報
ペンデュラムモンスターだけが持つ情報をまとめたオブジェクト。
```
object PendulumInfo
{
  "scale": number,
  "text" : string | null,
}
```
- `scale`: ペンデュラムスケール
- `text`: ペンデュラム効果
  - ペンデュラム効果を持たない場合は`null`(プロパティを省略)でもよい。

### パック情報
カードパックの情報を表すオブジェクト。
```
object CardPack
{
  "pid"  : string,
  "name" : string,
  "date" : string,
  "cards": CardPackItem[],
}
```
- `pid`: 商品ID
  - 公式データベースにおいて、パック個別ページURLの`pid=***`の部分で確認できる。
  - カードIDと異なり桁数が多い(例: `1000008502000`)ため、数値(`number`)ではなく文字列(`string`)で保持する。
  - TCG版パックの場合は末尾に`e`を付ける(例: `"2000001657000e"`)。
- `name`: パック名
- `date`: 発売日
  - 形式は`yyyy-MM-dd`
  - 日時として解釈できるなら他の形式でもよい。
- `cards`: 収録カードの配列

### パック収録カード情報
カードパックに収録されているカードの情報を表すオブジェクト。
```
object CardPackItem
{
  "id"    : number,
  "number": string,
}
```
- `id`: カードID
  - `DataSet.cards`における各カードのIDと対応していなければならない。
- `number`: カードナンバー (例: `"RC04-JP009"`)
  - 公式データベースにおいて、なぜかパック個別ページでは確認できない。
  - カード個別ページの「収録シリーズ」の欄で確認できる。
  - 最初期のパックではカードナンバーは存在しない。この場合は空文字列(`""`)。

## 列挙型
- 特定の文字列のみが有効なプロパティにおいて、その文字列を定義するのが列挙型である。
- いずれの列挙型においても、一覧は13期(2025年4月)現在のものであり、今後追加される可能性はある。

### カードタイプ
`Card.type`の値として有効な文字列。
```
enum CardType
[
  "モンスター",
  "融合",
  "儀式",
  "シンクロ",
  "エクシーズ",
  "リンク",
  "通常魔法",
  "フィールド魔法",
  "装備魔法",
  "永続魔法",
  "速攻魔法",
  "儀式魔法",
  "通常罠",
  "永続罠",
  "カウンター罠",
]
```
- `モンスター`は、メインデッキに入るモンスターのうち`儀式`でないものを指す。
  - それ以外のモンスターカードにおいては`"モンスター"`は入れない(例: `"融合モンスター"`は無効)。
  - ペンデュラムモンスターはカードタイプではなく能力(`MonsterInfo.ability`)に含める。
- 魔法カードにおいては`"魔法"`まで入れる(例: `"装備"`は無効)。
- 罠カードにおいては`"罠"`まで入れる(例: `"カウンター"`は無効)。

### 属性
`MonsterInfo.attribute`の値として有効な文字列。
```
enum Attribute
[
  "光属性",
  "闇属性",
  "水属性",
  "炎属性",
  "地属性",
  "風属性",
  "神属性",
]
```
- `"属性"`まで入れる(例: `"光"`は無効)。
- 「火属性」ではないことに注意。

### 種族
`MonsterInfo.type`の値として有効な文字列。
```
enum MonsterType
[
  "魔法使い族",
  "ドラゴン族",
  "アンデット族",
  "戦士族",
  "獣戦士族",
  "獣族",
  "鳥獣族",
  "機械族",
  "悪魔族",
  "天使族",
  "昆虫族",
  "恐竜族",
  "爬虫類族",
  "魚族",
  "海竜族",
  "水族",
  "炎族",
  "雷族",
  "岩石族",
  "植物族",
  "サイキック族", // 6期で追加
  "幻竜族",       // 9期で追加
  "サイバース族", // 10期で追加
  "幻想魔族",     // 12期で追加
  "幻神獣族",
  "創造神族",
]
```
- `"族"`まで入れる(例: `"魔法使い"`は無効)。

### 能力
`MonsterInfo.ability`の値として有効な文字列。
```
enum Ability
[
  "特殊召喚",
  "ペンデュラム",
  "トゥーン",
  "デュアル",
  "ユニオン",
  "スピリット",
  "リバース",
  "チューナー",
]
```
- 「通常」と「効果」は能力には含めず、`MonsterInfo.effect`で指定する。
- 複数の能力を持つ場合(例: チューナーかつリバース)、それらを`/`で区切って全て書く(例: `チューナー/リバース`)。

## リンクマーカーの向き
- リンクモンスターにおいて`MonsterInfo.def`の値はそのリンクマーカーの向きを表す値になる。
- 上位ビットから [右上, 上, 左上, 右, 左, 右下, 下, 左下] の順に並べた 8bit の数値である。
  - 該当する向きにリンクマーカーがある場合は、そのビットを`1`とする。
- JSONの仕様上、二進表現(例: `0b1011`)は許されないので、実際にはそれを十進にした値で記述する。
- 例
  - リンクマーカーが [右下, 左下] の場合
	- 二進表現では `0b_0000_0101`
	- `MonsterInfo.def`の値としては`5`になる。
  - リンクマーカーが [上, 右, 左, 下] の場合
	- 二進表現では `0b_0101_1010`
	- `MonsterInfo.def`の値としては`90`になる。

## カード情報の例

```
{
  "id": 4007,
  "name": "青眼の白龍",
  "ruby": "ブルーアイズ・ホワイト・ドラゴン",
  "en_name": "Blue-Eyes White Dragon",
  "type": "モンスター",
  "text": "高い攻撃力を誇る伝説のドラゴン。どんな相手でも粉砕する、その破壊力は計り知れない。",
  "monster_info": {
    "attribute": "光属性",
    "type": "ドラゴン族",
    "level": 8,
    "atk": 3000,
    "def": 2500
  }
}
```

ペンデュラムモンスターの例
- `monster_info.ability`に`"ペンデュラム"`を追加する。
- `pendulum_info`を追加する。
```
{
  "id": 14960,
  "name": "覇王黒竜オッドアイズ・リベリオン・ドラゴン－オーバーロード",
  "ruby": "はおうこくりゅうオッドアイズ・リベリオン・ドラゴン－オーバーロード",
  "en_name": "Odd-Eyes Rebellion Dragon Overlord",
  "type": "エクシーズ",
  "text": (省略),
  "monster_info": {
    "attribute": "闇属性",
    "type": "ドラゴン族",
    "effect": true,
    "ability": "ペンデュラム",
    "level": 7,
    "atk": 3000,
    "def": 2500
  },
  "pendulum_info": {
    "scale": 4,
    "text": (省略)
  }
}
```

リンクモンスターの例
- `monster_info.def`がマーカーの向きを表す値となっている。
- `26` = `0b_0001_1010` → [右, 左, 下]
```
{
  "id": 18314,
  "name": "アティプスの蟲惑魔",
  "ruby": "アティプスのこわくま",
  "en_name": "",
  "type": "リンク",
  "text": (省略),
  "monster_info": {
    "attribute": "地属性",
    "type": "昆虫族",
    "effect": true,
    "level": 3,
    "atk": 1800,
    "def": 26
  }
```

魔法カードの例
- `monster_info`が無いためシンプルな見た目になる。
```
{
  "id": 18441,
  "name": "アディショナル・ミラー・レベル７",
  "ruby": "アディショナル・ミラー・レベルセブン",
  "type": "速攻魔法",
  "text": (省略)
}
```
